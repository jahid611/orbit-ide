Orbit Icons est le thème d'icônes de fichiers livré avec Orbit, actif par défaut. Les langages et les outils y portent leur logo officiel ; tout ce qui est générique (dossiers, fichier simple, image, verrou…) est dessiné dans un même style plat.

## À quoi ça sert

Dans l'explorateur et sur les onglets, tu repères d'un coup d'œil le type d'un fichier : un logo de langage pour le code, une forme colorée pour un dossier, une image, un terminal, une base de données ou un fichier de configuration.

## Ce que contient le thème

- **Logos officiels** des langages et outils, issus de Devicon (licence MIT). Les logos noirs sont éclaircis pour rester lisibles sur un thème sombre.
- **Icônes génériques** dessinées pour Orbit : fichier, texte, image, terminal, base de données, verrou, réglages, git, archive, tableau, vidéo, audio, paquet, dossiers.
- Une grille et un trait communs, pour que l'ensemble reste cohérent.

## Changer de thème d'icônes

- Dans le [Studio](/docs/personnaliser/studio), section « Interface », ligne « Thème d'icônes ».
- Ou avec la palette de commandes : « Preferences: File Icon Theme » (`workbench.action.selectIconTheme`). Le réglage est `workbench.iconTheme`, dont la valeur par défaut est `orbit-icons`.

La galerie d'extensions d'Orbit est Open VSX : un thème d'icônes publié là s'installe comme une extension, puis se choisit par les mêmes moyens.

## Les icônes de l'interface d'Orbit

Les pages d'Orbit (vue Orbite, tableau de tâches, StarCapture, etc.) utilisent leurs propres icônes en SVG, dessinées pour Orbit, et non le thème d'icônes de fichiers. Le thème que tu choisis ne les change pas.

## Réglages

| Réglage | Défaut | Effet |
|---|---|---|
| `workbench.iconTheme` | `orbit-icons` | Le thème d'icônes de fichiers. |
