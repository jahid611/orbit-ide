Les raccourcis de l'éditeur ne marchent que lorsque tu n'es pas en train de taper dans un champ (nom du montage, texte, valeur numérique). Dans un champ, `Échap` rend le focus à l'éditeur. La touche `?` affiche un rappel des principaux raccourcis directement dans l'éditeur.

Sur macOS, `Ctrl` devient `⌘`, `Maj` devient `⇧` et `Alt` devient `⌥`, sauf mention contraire. Les touches seules sont les mêmes partout.

## Commandes d'Orbit

| Action | Windows / Linux | macOS |
|---|---|---|
| Ouvrir StarCapture | `Ctrl+Alt+S` | `⌥⌘S` |
| Exporter la vidéo (dans l'éditeur) | `Ctrl+E` | `⌘E` |
| Annuler | `Ctrl+Z` | `⌘Z` |
| Rétablir | `Ctrl+Maj+Z` | `⇧⌘Z` |

## Lecture et navigation

| Action | Raccourci |
|---|---|
| Lecture / pause | `Espace` |
| Pause | `K` |
| Lecture avant, puis plus vite à chaque appui (×2 jusqu'à ×8) | `L` |
| Lecture arrière, puis plus vite à chaque appui (×2 jusqu'à ×8) | `J` |
| Image précédente / suivante | `←` / `→` |
| Une seconde en arrière / en avant | `Maj+←` / `Maj+→` |
| Coupe précédente / suivante | `↑` / `↓` |
| Début / fin du montage | `Home` / `End` |
| Plein écran | `F` (`Échap` pour sortir) |

## Édition

| Action | Windows / Linux | macOS |
|---|---|---|
| Couper à la tête de lecture | `S` | `S` |
| Outil lame (couper en cliquant) | `C` | `C` |
| Outil sélection | `V` | `V` |
| Supprimer la sélection | `Suppr` ou `Retour arrière` | `Suppr` ou `Retour arrière` |
| Supprimer et recoller | `Maj+Suppr` | `⇧Suppr` |
| Magnétisme (activer / désactiver) | `N` | `N` |
| Montage en décalage (activer / désactiver) | `R` | `R` |
| Tout sélectionner | `Ctrl+A` | `⌘A` |
| Copier les clips sélectionnés | `Ctrl+C` | `⌘C` |
| Coller à la tête de lecture | `Ctrl+V` | `⌘V` |
| Dupliquer | `Ctrl+D` | `⌘D` |
| Désélectionner et revenir à l'outil sélection | `Échap` | `Échap` |

## Repères et zoom

| Action | Windows / Linux | macOS |
|---|---|---|
| Poser un marqueur | `M` | `M` |
| Point d'entrée | `I` | `I` |
| Point de sortie | `O` | `O` |
| Effacer entrée et sortie | `X` | `X` |
| Zoomer sur la timeline | `+` | `+` |
| Dézoomer | `-` | `-` |
| Tout voir | `Maj+Z` | `⇧Z` |

## Souris

| Geste | Effet |
|---|---|
| Clic sur un clip | Sélectionne le clip et celui qui lui est lié |
| `Alt` + clic | Sélectionne le clip seul, sans son lié |
| `Maj` ou `Ctrl` + clic | Ajoute ou retire un clip de la sélection |
| Glisser dans le vide de la timeline | Sélection au lasso |
| Clic dans le vide de la timeline | Place la tête de lecture |
| Glisser une poignée d'un clip | Raccourcit le clip |
| `Alt` + glisser une poignée | Raccourcit le clip sans son lié |
| `Ctrl` + molette | Zoom sous le curseur |
| `Maj` + molette | Défilement horizontal |
| Double-clic sur un média de la bibliothèque | Pose le média à la tête de lecture |
| Glisser la règle | Déplace la tête de lecture |

## Limites

- Les touches seules (`S`, `C`, `V`, `N`, `R`, `M`, `I`, `O`, `X`, `J`, `L`) ne réagissent pas quand `Ctrl` ou `⌘` est tenu, sauf pour les combinaisons listées ci-dessus.
- `Ctrl+Alt+S` fonctionne même quand un terminal a le focus.
