# Personnaliser Orbit

Le **Studio** (Ctrl+Alt+, ou ⌥⌘,) regroupe l'apparence et les préférences de Claude.

- **Thèmes** : Cosmos (par défaut, translucide), Midnight, Aurora, Ember, Void, Paper.
- **Dispositions** en un clic : Cursor, Antigravity, Zen, Classique.
- **Interface** : panneaux flottants, arrondis, onglets en pilule, verre dépoli, animations, fond d'écran.
- **CSS libre** : n'importe quelle règle, appliquée en direct.
- **Profil** : exporte tes réglages dans le presse-papiers pour les reprendre sur une autre machine.

**À savoir**

- Le fond d'écran ne se voit qu'avec un thème translucide comme Cosmos.
- Le verre dépoli sollicite la carte graphique : coupe-le si l'interface devient moins fluide.
- Une règle CSS trop large peut rendre l'interface inutilisable ; vide le champ « CSS libre » (réglage `orbit.ui.customCss`) pour revenir en arrière.
